# 0.4.1 更新後登入保留

- 移除啟動時 SSO 驗證失敗直接完整 logout 的路徑。
- 401／403／帳號不符只標記 SSO 需重新驗證，不刪其他服務憑證、網站 Cookie、課表或 Widget。
- 回應格式缺漏與網路錯誤視為暫時不可驗證，保留本機身分與快取。
- 新登入增加 identity generation，避免較早的啟動驗證回應覆蓋新登入。
- Moodle／活動等服務依自己的憑證與校方回應決定是否可用；本機帳號不是偽造校方驗證成功。
- 使用者主動登出仍完整清除，切換帳號仍須先登出，維持帳號隔離。
- 0.4.0 以前已被清除的資料無法從新版自動恢復；需重新登入一次建立後才能保留。

驗證：SSO拒絕保留資料、格式錯誤保留資料、舊回應不覆蓋新登入與登出完整清除皆有回歸測試。

發布驗證：全專案分析無問題，174項測試通過（concurrency=2），APK建置／簽署成功，0.4.1下載HTTP200。

## 功能入口

- Moodle／點名使用已保存的Moodle Token並向Moodle確認身分，不被SSO過期擋住。
- 活動保留自己的Cookie，失效時只要求重連活動。
- 課表同帳號快取在SSO過期後仍可開啟；手動抓取校方新資料才需要校務憑證。
- 首頁及設定清楚區分「校務需要重新連接」與「暫時無法連線」，不強制整個App登出。

## 測試覆蓋

- SSO 401 不呼叫任何清理、不刪 Moodle／活動資料及課表。
- 身分格式缺漏標記為暫時不可驗證。
- 舊啟動回應不覆蓋新登入，同時重連只發一個請求。
- SSO過期仍可用Moodle自己的Token查課程；主動登出後舊Repository不可再送請求。
- 保留本機帳號不代表可跳過校方驗證或用不同帳號的新密碼自動登入。
