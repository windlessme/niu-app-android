# 註冊資訊與在學證明 0.5.0

入口：首頁／校園→註冊資訊。沿用現有校務Session與設計元件。

校方來源：教務系統→學籍及畢審→註冊作業→查詢註冊。
頁面`/NIU/Application/ENR/ENR50/ENR5020_01.aspx`，證明由校方`/MvcTeam/AcadeExport/StudyProved/{本人學號}`取得。

目標：提供註冊原始資訊與本人在學證明的瀏覽／儲存，未知值不當成已繳費或已完成；保留校方頁面入口。
證明檔案含個資，僅App私人暫存與使用者選擇的目的位置，不放到APK下載server。

實作與測試結果完成後補記。

發布結果：全專案分析無問題，196項測試通過，Android APK建置與簽署成功，0.5.0公網下載HTTP200。原生外部PDF閱讀程式及文件儲存選擇器仍待裝置操作驗證，不宣稱已實測所有閱讀App。

資料呈現原則：沿用校方文字，不把欠費／貸款／註冊假等欄位自行推算為最終註冊結論；若校方有明確在學狀態或註冊日期，分別顯示，不把空白日期解釋為未註冊。

已驗證首頁／校園入口的路由與既有導覽回歸；私人Cookie仍留在使用者指定的外部暫存位置，未納入程式資產。

PDF預覽與保存分開：預覽不代表已儲存到Downloads；保存由Android文件建立介面選擇位置，使用者取消不顯示成功。

權限範圍：不增加任意查詢學號欄位，不以不同學號探索校方證明服務；依當前登入身分核對後才取得本人證明。

## 實際提供欄位

校方學生DataGrid提供註冊學年期、在學／註冊狀態、註冊日期、超商繳費收據、收據上傳日期、備註。
PAY1–PAY5雖在校方JS欄位配置出現，當前表格沒有提供費用／貸款／註冊假／欠書明細值，顯示「校方未提供」，不捏造完成狀態。

## 實作檔案

- `features/registration/registration_data.dart`：實際欄位擷取與本人身分核對。
- `registration_screen.dart`：資料卡片、瀏覽／下載操作。
- `certificate_service.dart`：隔離HTTP下載、PDF驗證、Session檢查及清除。
- Android `RegistrationDocuments.kt`：FileProvider預覽與ACTION_CREATE_DOCUMENT保存。
- 不新增Flutter依賴；預覽使用裝置PDF閱讀程式，未安裝時明確提示，不假裝內建閱讀器已完成。
