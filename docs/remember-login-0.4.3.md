# 0.4.3 記住校務登入

使用者主動開啟「記住帳號密碼」後，成功確認校方身分才將同帳號憑證保存到裝置安全儲存。
重新授權在校方登入頁填入，驗證碼與登入提交保留由使用者操作。

- 不把密碼存到網站localStorage、URL或一般偏好設定。
- 只在確切校方HTTPS登入頁填入，不覆蓋使用者已編輯內容。
- 設定可清除已記住的登入，關閉選項或登出清除保存密碼。
- 登出與儲存並行時不得重新寫回已登出帳號。

測試與發布結果完成後補記。

發布：全專案分析無問題、184項測試通過、Android APK建置與簽署成功、0.4.3公網下載HTTP200。真實校方人機驗證仍由使用者在裝置上完成。

已驗證：prefill DOM fixtures 通過，涵蓋特殊字元編碼、input/change事件、來源／路徑／iframe限制、不覆蓋已有輸入與不自動提交。全專案靜態分析無問題。

新增 `features/authentication/remember_school_login.dart` 與安全儲存key；`LoginScreen` 負責勾選／預填，`SettingsScreen` 透過可選callback清除。使用者未啟用不會存入帳密。

使用方式：登入頁開啟記住選項→在校方頁面輸入帳密並完成人機驗證→登入成功後保存。下次重新授權自動填入；若校方頁面已有使用者輸入，保留既有內容。忘記選項不等於全域登出，不清除已有效的其他服務Token。

若校方帳密變更，使用者可修改自動填入內容；只有新帳密成功驗證後才替換保存值。現有Token不包含可還原的密碼，升級不會自動知道舊密碼，需要開啟選項後成功登入一次。
